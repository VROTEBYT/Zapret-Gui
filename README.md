Zapret GUI

Zapret GUI — Windows-приложение для удобного управления Zapret и tg-ws-proxy через единый графический интерфейс.

Проект объединяет необходимые инструменты в одной программе, делая их запуск, настройку и контроль работы проще и удобнее.

✨ Возможности

Zapret — управление запуском и остановкой инструмента.

tg-ws-proxy — интеграция управления прокси в приложение.

Графический интерфейс — основные функции доступны без необходимости постоянно использовать командную строку.

Проверка конфигурации — инструменты для проверки компонентов и настроек.

Быстрая и полная проверка — проверка доступных конфигураций.

Мониторинг работы — отображение состояния программы и обработанных пакетов.

Система обновлений — возможность проверки новых версий приложения.

Меню поддержки — отдельный раздел с информацией о поддержке проекта.

📥 Установка

Откройте раздел Releases.

Выберите последнюю доступную версию.

Скачайте ZapretGUI.exe.

Запустите приложение.

Актуальная версия программы публикуется в разделе Releases.

🔄 Обновления

Следите за выходом новых версий в разделе GitHub Releases.

📌 О проекте

Zapret GUI создаётся с целью объединить несколько инструментов в одном приложении с понятным интерфейсом и удобным управлением.

Проект продолжает развиваться, а новые функции и улучшения появляются в последующих версиях.

Zapret GUI — всё необходимое в одном окне.
